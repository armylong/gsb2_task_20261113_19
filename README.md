# HAR 本地脱敏工具

本地运行的 HAR(HTTP Archive)流量脱敏网页。浏览器导出的 HAR 常携带登录凭据、Cookie、
用户隐私字段,本工具帮助你在把文件交给他人复现问题之前:**先检查有什么敏感内容 →
确认脱敏结果 → 再导出可被标准 HAR 工具读取的脱敏文件与摘要**。

技术栈:Python + FastAPI + 原生 HTML/CSS/JavaScript(无前端构建、无外部账号、无外部服务)。

## 安全边界

- 服务**只监听 `127.0.0.1`**,同一台机器的浏览器访问;
- **不会访问 HAR 里出现的任何 URL**,不发起任何网络请求到外部服务;
- 所有数据只保存在服务进程内存中,「清空」立即释放,不写磁盘、不入库;
- 访问日志会剥掉 URL 查询串(避免 token 落盘),请求体与响应体从不写日志;
- 原始 HAR 永远不会被覆盖,导出的都是新文件;
- 页面所有 HAR 数据通过 `textContent`/DOM API 渲染,HAR 内的 HTML/`<script>`
  只会以文本显示,不会被执行。

## 快速启动

需要 Python 3.10+(开发与测试使用 3.12)。

```bash
# 1. 创建虚拟环境并安装依赖
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 2. 启动(默认仅监听本机 127.0.0.1:8000)
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

浏览器打开 <http://127.0.0.1:8000/>。

> 建议用隔离模式运行 Python(忽略工作目录与环境变量中的注入模块):
> `.venv/bin/python -I -m uvicorn app.main:app --host 127.0.0.1 --port 8000`

## 使用流程

1. 点击「上传 HAR」选择浏览器导出的 `.har`,或点击「载入演示数据」使用内置虚构 HAR;
2. 左侧按方法/地址/状态码关键词筛选请求,点击条目查看请求头、查询参数、请求体、
   响应头与响应体;损坏的条目会红色标记且不影响其他条目;
3. 右侧「发现项」列出全部敏感命中,**原文默认遮盖**,点「查看原文」才会显示;
4. 可对单条或批量发现项选择处理方式:
   - **固定遮盖**:替换为 `[REDACTED]`;
   - **删除字段**:移除该字段/参数/Cookie 子项(其他兄弟字段保留);
   - **一致化代号**:同一原值在任何请求、任何位置都得到同一代号(如 `TOKEN_001`),
     不同原值不会合并,仍可看出请求间关联;
5. 在「规则」页新增/启停/删除自定义规则(按字段名或正则,指定检查位置);
   非法正则会被拒绝并提示,已有扫描结果不受破坏;
6. 点击「切换到脱敏预览」核对该条目改写结果,预览与导出文件由同一份代码生成,完全一致;
7. 「导出脱敏 HAR」得到可被标准 HAR 工具读取的新文件;「下载脱敏摘要」得到 Markdown 报告。
   仍有未处理发现项或未检查内容时,页面横幅与摘要都会明确告警。

## 默认识别规则

| 规则 | 检查位置 | 匹配方式 |
| --- | --- | --- |
| Authorization 等凭据头 | 请求头 | 字段名(大小写不敏感) |
| 全部 Cookie / Set-Cookie 子项 | 请求头、响应头 | 字段名通配 |
| token/password/secret/key/email/phone 等敏感字段名 | 查询参数、请求体、响应体 | 字段名子串(大小写不敏感) |
| 邮箱地址 | 查询参数、请求体、响应体 | 值正则 |
| 中国大陆手机号 | 查询参数、请求体、响应体 | 值正则 |
| Bearer 令牌 / JWT | 全部五个位置 | 值正则 |
| 硬编码密钥形态(`token="..."`、`password=...`) | 查询参数、请求体、响应体 | 值正则(只替换值部分) |

字段名匹配为大小写不敏感的子串匹配;同名重复参数(查询串、表单)会逐个全部检查;
同一位置被多条规则命中只生成一条发现项(规则聚合),因此不会产生互相矛盾的替换结果。

## 支持的正文形态

- 请求体:JSON(含嵌套对象/数组)、`application/x-www-form-urlencoded`(含重复参数);
- 响应体:普通文本、JSON、HAR 标记为 `encoding: base64` 的文本(解码检查后重新编码,
  保留 base64 表达方式与中文);
- 二进制响应、无法解码的 base64、畸形 JSON 会列为**未检查**(红色提示),不会显示成安全;
- 改写后同步更新 `content.size`、`request.bodySize`、`response.bodySize`,
  头变化时 `headersSize` 置为 `-1`(HAR 规范中的"未知"),不保留错误的旧长度;
- 未修改的字段(顺序、时间、状态码、timings 等)原样保留;导出包含全部条目,不仅是当前筛选结果。

## 运行自动化测试

```bash
.venv/bin/python -I -m pytest tests/ -v
```

测试重点覆盖:

- 五个位置(请求头/响应头/查询参数/请求体/响应体)的完整脱敏;
- 一致化代号:同原值同代号、跨请求跨位置一致、不同原值不混淆;
- 重复查询/表单参数保留、嵌套 JSON 与数组不丢、中文保留;
- base64 中文响应的解码-改写-重新编码往返与长度更新;
- 删除单个 Cookie 子项不影响其他 Cookie,Set-Cookie 镜像字段同步;
- 坏条目标记、整文件无法解析时保留当前工作区;
- 非法正则拒绝且不破坏已有结果、重新扫描不叠加旧结果;
- 导出 HAR 与摘要中不包含任何敏感原值、文件名不含用户数据;
- HAR 内 `<script>` 不被执行(前端静态审查 + 无头浏览器 DOM 验证)。

## 目录结构

```
app/
  main.py        FastAPI 路由、序列化、日志查询串过滤
  models.py      Rule / Target / Finding / UncheckedItem 数据模型
  rules.py       内置规则、规则编译与校验
  hario.py       HAR 读取、条目规范化、正文解析(json/form/base64/二进制)
  scanner.py     扫描引擎:位置遍历、多规则聚合、一致化代号分配
  sanitizer.py   脱敏执行:精确改写 HAR 深拷贝、长度更新、Cookie 镜像同步
  session.py     内存工作区(单例)、处理决定继承、预览/导出共用缓存
  summary.py     Markdown 脱敏摘要(保证不含原值)
  demo.py        内置虚构演示 HAR 生成器
static/
  index.html     单页结构
  styles.css     样式
  app.js         原生 JS(全部数据走 textContent 渲染)
tests/           pytest 自动化测试
```

## 已知限制

- JSON 对象内若存在重复键,受 Python 标准 JSON 解析限制只保留最后一个键值;
  重复的查询参数与表单参数不受此限制,会完整保留;
- 正则规则按值匹配,过于宽泛的正则(如 `.*`)可能产生大量命中,按需收窄模式;
- 本工具不做 HAR 来源真实性校验,只负责敏感内容识别与脱敏。
